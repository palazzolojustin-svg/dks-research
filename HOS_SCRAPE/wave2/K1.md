# K1: QWI firm-size (500+) and firm-age cuts for the HoS county DiD
## Methodology
- Goal: rerun J02's county DiD on the QWI large-firm (firmsize 5 = 500+ employees) and mature-firm (firmage 5 = 11+ yrs) cuts so excess jobs isolate large chains like DICK'S.
- KEY DATA FINDING (verified in LEHD file listing, nj): the county x NAICS-4 file J02 used (`qwi_<st>_sa_f_gc_n4_op_u`) carries firmage/firmsize columns but they are only the "all" value (0). Firm-size/age detail exists ONLY in separate files `qwi_<st>_sa_fs|fa_<geo>_<ind>`, and at COUNTY level only with NO industry detail (`gc_ns`); NAICS-4 detail exists only at STATE level (`gs_n4`). So the cut "county x 4591 x 500+ firms" does NOT exist anywhere in the free bulk data. (I first wasted a download pass on the `sa_f_gc_n4` files before finding this.)
- What I could run: county ALL-INDUSTRY Emp for firmsize 5 (500+), private ownership (A05), sex/age/race/edu all, y/y vs a same-state control (non-event counties with data both periods, >=4), k=0..3 from the opening quarter (same DiD as J02). Downloaded `sa_fs_gc_ns` for 19 states (AL AZ DE FL GA IA IL KS MA NC NH NJ NY OH OK PA VA; TX MN TN LA not finished/missing). Firm-age (`sa_fa_gc_ns`) downloads did not finish within budget; the age cut was not computed (it would have the identical all-industry noise problem).
- Noise calibration ("placebo SD"): SD of the same excess statistic across control counties of 0.5x-2x the event county's size, per event.
- Scripts: scripts/K1_qwi_fs.py (download+filter), scripts/K1_analysis.py. Data: data/K1_qwi_<st>_fs_gcns.csv, data/K1_qwi_cut_yoy_long.csv, data/K1_qwi_cut_event_summary.csv, data/K1_pooled.csv. Types from J13 (net-new: Boston, Pittsburgh, Jersey City, Glendale, Live Oak; relocation core: Minnetonka, Johnson City, Davenport, Champaign, Scranton, Tampa, Harris, Fayetteville, Amherst; "ext" adds address-proven relocations Freehold, Brandon, Dallas, Victor, Knoxville).

## NEW findings
- [X/method] The large-firm cut is NOT identifiable at county level. Event-county 500+-firm private employment is 18K-588K (median 87K); placebo SD of the excess across comparable control counties is 1,058-3,496 jobs (median 1,935), i.e. 10-30x the ~100-job HoS signal. Per-event size500 excess is therefore random: e.g. Boston k0 -15,041 / k1 +5,094; Latham k0 -6,585; Chesapeake +3,239; Miami Kendall +3,863; Jersey City -5,056; Johnson City -670; Fayetteville -438 (k0) / +161 (k1); Scranton -154 / +1,491; Davenport +423 / +35. No event is distinguishable from zero.
- [X] Pooled large-firm excess (data/K1_pooled.csv; all-industry 500+ firms, so $ = INFERENCE and meaningless): net-new n=3 mean -1,350 / median -612 jobs; relocation core n=5 mean -352 / median +112 (= $24M at $215K, $7.8M at $70K, by chance); relocation ext n=6 mean -371 / median -177; all events n=18 mean -5 / median +164 (k0-3 mean). Standard errors are ~1,000+ jobs per event, so none of these are evidence for or against $20M.
- [B] Benchmark comparison, same events (all-firm 4591 from J02 vs QCEW y1 from B5): J02 4591 mean-of-quarters excess: net-new n=3 (Jersey City 36, Live Oak 94, Glendale 244) mean +125 / median +94 -> $26.8M / $20.2M at $215K and $8.7M / $6.6M at $70K; relocation core n=3 (Harris 120, Fayetteville 84, Tampa -26) mean +59 / median +84 -> $12.8M / $18.1M at $215K, $4.2M / $5.9M at $70K; QCEW y1 (this repo's B5): net-new n=5 mean +190 / median +227 (= $40.9M / $48.8M at $215K; $13.3M / $15.9M at $70K); relocation core n=9 mean +103 / median +111 (= $22.1M / $23.9M at $215K; $7.2M / $7.8M at $70K); all 35 events mean +118 / median +102 (= $25.4M / $21.9M; $8.3M / $7.1M). These are the only usable pooled numbers; the QCEW split in J13 stands (relocation matches Street ~$20M only at $215K/job).
- Per-event table (all-firm J02 4591 mean vs large-firm cut): in data/K1_qwi_cut_event_summary.csv columns J02_4591_mean, size500_k0/k1/mean, size500_psd, qcew_y1, plus $215K/$70K columns. Where J02 had Q4-2025 reads (Freehold +158, Kennesaw +245, Glendale +244, Live Oak +94, Brandon -62, Dallas -296) no large-firm cut can be computed because 2025Q4 is the last quarter and k>=1 not available for those, and k0 county all-industry noise is as above (the 2025Q4 events were not run: size500 columns blank / NaN).
