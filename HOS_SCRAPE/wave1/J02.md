# J02: State labor-market data (Census QWI by county x NAICS 4591; state QCEW/CES portals)

## Methodology
- Goal: sources faster/finer than BLS QCEW (which in these files ends 2026Q1). Tested: (1) Census QWI API: needs an API key now ("Missing Key"), so skipped (no keys). (2) LEHD bulk CSVs, no key: `https://lehd.ces.census.gov/data/qwi/latest_release/<st>/qwi_<st>_sa_f_gc_n4_op_u.csv.gz` (county x 4-digit NAICS, private ownership). Downloaded 10 states (OH NJ FL TX GA AZ AL NC VA KS; TX 2.0GB, GA 1.1GB), filtered to industry 4591 (NAICS 2022 "sporting goods, hobby, musical instrument, book & misc retailers"; this QWI vintage has no 4511), sex 0, age A00, race/ethnicity/education/firm age/firm size = all, ownercode A05. Variables: Emp, HirA (all hires), Sep, FrmJbC.
- Event counties from THESIS_SCRAPE/raw/B5_hos_events.csv (open quarter k0). For each event county and k=0..3: y/y change in Emp and HirA vs same quarter prior year, minus the y/y growth of a control (all other counties in same state with non-null data both periods, excluding all HoS-event counties; n=13-83 counties, shown in data). "Excess" = county actual minus (county last year x control y/y). This is a difference-in-differences, one county, noisy.
- Latest QWI quarter = 2025Q4 in all 10 states (one quarter OLDER than QCEW 2026Q1). So QWI does NOT extend the horizon; value is hires/separations and a second, independent employment measure. Unreached (time/size): NY DE OK PA MA NH IL IA MN TN LA CO (events there are pre-2025Q3 or already in B5).
- State portals 2026Q2: BLS county QCEW 2026Q2 is scheduled for 2026-12-02 (bls.gov/cew/release-calendar); web search of TX/FL/OH state QCEW pages found no state release ahead of BLS. State CES metro series are Retail Trade total, too broad to see one 100-job store. Conclusion: no 2026Q2 county jobs data exists yet anywhere free.
- Scripts: scripts/J02_qwi_dl.py, J02_qwi_retry.sh, J02_qwi_filt.py, J02_qwi_yoy.py, J02_qwi_analysis.py. Data: data/J02_qwi_<st>_4591.csv, data/J02_qwi_yoy.csv, data/J02_qwi_event_table.csv. Novelty: grep for QWI across THESIS_SCRAPE, EVIDENCE_BOOK, digest = none (J14 only mentions it as a plan).
- Caveats (important): 4591 includes hobby, music, book, misc retailers and ALL sporting-goods chains in the county (Academy, Big 5, Hibbett, closures); QWI Emp = jobs at any time in quarter, includes seasonal; control y/y is itself noisy (FL/OH-type controls show -3% to -8%). Treat as B/C, not A. Dollar values = INFERENCE (jobs x $215K and x $70K).
