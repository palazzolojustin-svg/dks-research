- Two method flaws in the earlier loops (H04/B8), confirmed by test queries:
  1. The FTS `forms` parameter silently returns total=0 when any listed form code is invalid (e.g. `424H/A`).
  2. FTS intermittently returns HTTP 500 or a body with no `hits` key. H04/B8 loops treated that as "end of results".
- Third method flaw: EDGAR FTS does not match a curly apostrophe. The query `"Dick’s" "occupancy cost"` returns 0 hits, against 264 for `"Dick's"`. Documents typeset with "Dick’s" are reachable only through the phrase `"Dick s"` (134 hits with "occupancy cost") or `"Dicks"`.

  - 702 docs in total, of which 294 accessions were new.
  - Of the 294, 89 were from CMBS depositors or trusts. The rest were structured-note 424B2s naming DKS stock (UBS, Citi, GS, Barclays), Synchrony and RREEF/CIM REIT supplements.
  - All 89 CMBS docs were fetched to `raw\B10_cache` (`scripts\B10_fetch.py`) and parsed (`scripts\B10_extract.py` → `raw\B10_review.txt`, 28 docs with DICK'S + sales context). Every row was read by hand.

[B10-5] **Method finding for anyone re-running EDGAR FTS (B8/B9/H-series):**
- Curly-apostrophe "Dick’s" is invisible to the query "Dick's". Use "Dick s" and "Dicks".
- The `forms` filter silently zeroes out on an invalid code.
- HTTP 500 must be retried, not treated as the end of results.
- The `"Dick s" "sales"` query alone added 107 FWP/424 docs that `"Dick's" "sales"` misses. For HoS/FH, though, no extra sales-bearing doc turned up.

## Evidence against / caveats
- All four new stores show 2018-19 productivity of $128-180/sf, well below the ~$280/sf national average. They are a reminder of a low-productivity legacy tail (Parma also renewed at a rent cut). That tail is consistent with parts of the older fleet not comping.
- 2019 figures are pre-COVID and pre-relocation-in-comp. They cannot be read against any current comp.
- Several "sales" are borrower-provided or approximate (Woodlands "approximately $12.7 million"). Blackstone Valley's sales date conflicts between filings (Jan-31-2019 vs Aug-31-2019).
- Cumberland Mall's anchor sales line ($217M 2020 excl. DICK'S/Round 1; $298M 2021 incl.) is rounded and mixes Costco/Round 1, so DICK'S cannot be isolated. B8's "$24mn" lender-Q&A figure stands.
