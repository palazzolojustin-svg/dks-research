# W01: footlocker.com catalog census (US) + champssports.com
## Method
- Snapshot 2026-10-07 (~21:00 UTC). footlocker.com and champssports.com category pages (public HTML, browser-impersonated GET via curl_cffi) embed the server-rendered facets, pagination totals and first-48 product list as JSON. No API keys, no login, no bulk-API calls.
- Respected robots.txt: did NOT use currentPage= or sort= pagination (disallowed). Instead used the site's own facet filter URLs (`?query=:relevance:collection_id:<c>:brand:<b>[:saleProduct:True][:style:<s>]`), which return an exact totalResults per slice. So listing counts and sale counts are exact populations; discount depth is computed on a sample (first 48 per slice, widened by style sub-slices; 100% coverage for most brands, partial for Nike/Jordan/adidas/Pro Standard big sale sets).
- Unit = "listing" (a product page/style as counted by the site's totalResults, one per model-colour product). "On sale" = site's saleProduct facet. Discount = (originalPrice - price)/originalPrice from the product record. Collections: men/women/kids shoes, men/women/kids clothing (accessories/hats excluded). Footlocker.com: men-s-shoes, women-s-shoes, kids-all-shoes, men-s-clothing, women-s-clothing, kids-all-clothing. Champs: all-men-s-shoes, all-women-s-shoes, kids-shoes, all-men-s-clothing, all-women-s-clothing, all-kids-clothing.
- Caveats: a listing can appear in more than one collection (e.g., unisex), so totals are listing-collection counts, not unique SKUs; ASICS brand filter returned 0 on both sites (filter bug), so ASICS is missing from sale/depth stats (facet shows 48/42/26 FL listings); no prior-date comparison obtained (no cache/tracker pull within budget), so this is a single point in time.
- Files: scripts/W01_fetch.py, W01_census.py, W01_census_champs.py, W01_analyze.py; raw/W01/{products.jsonl,champs_products.jsonl,brand_counts.csv,champs_brand_counts.csv}; data/W01_fl_champs_catalog_2026-10-07.csv (9,593 sampled product rows with price, list, discount, brand, collection).
