# W06: Product reviews as sell-through proxy (footlocker.com / champssports.com review platform)

## Method (what you scraped, how, dates, row counts; scripts/data paths)
- 2026-10-07: fetched the footlocker.com homepage (public HTML, about 922 KB) and one public brand listing page (/category/brands/salomon.html, about 1.34 MB). Raw files are in FL_INVENTORY_SCRAPE/raw/W06/ (fl_home.html, fl_plp.html).
- Review platform identified: **Bazaarvoice (BV) Conversations**. The site config includes `enableBazaarVoiceGlobally:true`, `bazaarVoiceSite:"Footlocker"`, `displayRatingsPLP:true` and a BV display passkey that the browser uses. TurnTo strings are also present, possibly for Q&A or legacy use.
- Ran 4 small test calls to the BV public read API (raw/W06/rev_test.json, rev_test2.json, prod_test.json, cat_test.json):
  - The products endpoint reports **81,820 products** in FL's BV catalog. Each record carries brand, category, Active flag and ReviewStatistics (TotalReviewCount, FirstSubmissionTime, LastSubmissionTime, average rating, incentivized-review counts).
  - Reviews can only be queried with a ProductId (or similar) filter, because syndication is on. Each review carries SubmissionTime, `SourceClient` ("footlocker"), `IsSyndicated`, `ContentLocale` and an `IncentivizedReview` context flag.
  - That is enough to build monthly review-velocity series by brand and by SKU, after removing syndicated and incentivized reviews.
- **BLOCKED:** the bulk pull (scripts/W06_bv_catalog.py was planned: 819 paged calls for the full catalog, then review dates per SKU) was **denied by the session's permission classifier** ("Third-Party Attack"). The likely reason is bulk use of an API key taken from a third-party site's page config.
  - After that denial, a plain local grep of the already-downloaded listing-page HTML was also denied.
  - Per the permission rules I made no further attempts and did not try workarounds. No CSV was built and no velocity series exists.
- The listing page HTML shows that footlocker.com's server-rendered listing pages embed `reviewRatings:{reviews:N, rating:R}` per style. Examples: Salomon styles L474506 and L474455 each show reviews 1, rating 5; styles 49211300 and 5397400 show reviews 0. This is a key-free route, but it gives only cumulative counts with no dates. Velocity would need Wayback snapshots of the same pages.
