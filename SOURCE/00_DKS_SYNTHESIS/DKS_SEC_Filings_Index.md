# DKS — SEC Filings Index (10-K, 10-Q, 8-K markdown conversions)

Source directory: `01_DKS_SEC_FILINGS/` (subfolders `10-K/`, `10-Q/`, `8-K/`). Filing dates are from each file header; periods follow DKS's fiscal calendar (fiscal year ends the Saturday closest to January 31; "fiscal 2025" ended January 31, 2026; fiscal 2023 was a 53-week year ending February 3, 2024). Foot Locker acquisition closed September 8, 2025.

Important caveat on 8-Ks: every 8-K markdown file contains only the 8-K body (cover page, Items, signature, exhibit index). No exhibit text (Ex. 99.1 press releases, Ex. 99.2 pro forma tables, Ex. 10.1 agreements) is included. Earnings numbers, pro forma line items and the preliminary Q1 FY2025 results therefore are "not in filing" and must be taken from the 10-Q/10-K files instead.
